## Synthèse de ma veille technologique
- **Définition en une phrase :**  La modularité en PHP consiste à organiser le code en plusieurs fichiers et fonctions réutilisables pour éviter la répétition.
- **Problème résolu pour le projet :** Éviter de copier le même code dans plusieurs pages, réduire les erreurs et faciliter la maintenance du projet Blog.
- **Mes 3 mots-clés :** require_once — Fonctions réutilisables — Principe DRY (Don't Repeat Yourself)
